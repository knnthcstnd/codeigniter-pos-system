# Simple POS System

A basic four-page Point-of-Sale website created using CodeIgniter 4.

## Features

- Landing page
- About page
- Customer Accounts page
- User Accounts page
- Static PHP arrays containing sample records
- Responsive navigation and table design
- No database required

## Requirements

- PHP 8.2 or newer
- Composer 2.0.14 or newer
- CodeIgniter 4
